# 모델 선택 체크리스트

- [ ] 제품군이 아닌 정확한 체크포인트·버전을 확인했습니다.
- [ ] 텍스트·이미지·영상·오디오 중 필요한 입력을 지원합니다.
- [ ] 전체 가중치 크기와 양자화 파일의 실제 크기를 확인했습니다.
- [ ] MoE의 활성 파라미터를 전체 가중치 크기로 해석하지 않았습니다.
- [ ] 기본 컨텍스트와 별도 설정이 필요한 확장 범위를 구분했습니다.
- [ ] 러너의 아키텍처·채팅 템플릿·비전/오디오 어댑터를 확인했습니다.
- [ ] 라이선스·이용약관과 원본 저장소를 확인했습니다.
- [ ] `omm fit`으로 현재 메모리 적합성을 확인합니다.
- [ ] `omm verify`로 실제 생성을 확인하고, 내 작업 예시로 품질을 평가합니다.

가중치 계산 예시와 RAM/VRAM 실측은 다릅니다. 설치·연결·생성·작업 품질도 각각 확인해야 합니다.

모델 추천: https://omm.run/models
